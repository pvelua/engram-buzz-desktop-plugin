# v0.1.0

Connect Buzz Desktop agents to ENGRAM to give them project skills, durable memory across sessions, and access to knowledge base articles.

## What's new

- **Configure** an ENGRAM identity for each agent, using a dedicated ENGRAM card in Settings or on the agent's configuration page.
- **Test** connection status and verify the restricted PAT role with a **Test** button that validates credentials, displays identity details, and warns if the restricted PAT is not restricted.
- **Equip** agents with six tools (`engram_skill`, `engram_recall`, `engram_remember`, `engram_search`, `engram_get_article`, and `engram_whoami`) operating under their own restricted PAT.
- **Direct** agents with an ENGRAM identity to call `engram_skill` before anything else on every new task, ensuring project skills load automatically.
- **Record** agent memories under project scope with `engram_remember` and receive transparent error messages if backend faults occur.
- **Route** connections per community with community-specific ENGRAM settings and distinct per-community ENGRAM identities.
- **Manage** settings with clear input field styling and a dedicated action button row for Save, Test, and Remove buttons in narrow panels.

## Before you start

1. Install Buzz Desktop 1.0.5 or later.
2. Connect Buzz Desktop to your community.
3. Create or join a project in ENGRAM.
4. Create an agent in ENGRAM, assign its project skill, and generate a restricted PAT.

## Known limits

- Agents run only while Buzz Desktop is open.
- The ENGRAM PAT is kept in the plug-in's storage on this computer, not in the Keychain; use a restricted PAT.
